## 1. 第一性原理与信息架构
| 思想 | 抽象描述 | 来源路径 |
|---|---|---|

| 一个东西一个样 | 同语义全站同形：进度恒为分段仪表、状态恒为方形色点、大数字恒为点阵；禁形态漂移 | 同上【参考提炼·需重新验证】 |

| 序号 tab 路由 | ( 01 ) 序号 + 大写标签，选中=墨底反白，hash 深链 + 键盘 1-N | 同上【参考提炼·需重新验证】 |

## 3. 状态色语义
| 思想 | 抽象描述 | 来源路径 |
|---|---|---|
| 三语义色 | 红=严重/告警、绿=工作中、琥珀=等待/警告；中性底 + 有限语义色，克制使用 | fork-clone/36-Jimmy设计语.md【参考提炼·需重新验证】 |
| 方形状态点 | 圆角小方块：绿=工作中（呼吸闪）、琥珀=等你/失败、灰=空闲、空=结束；圆点仅留给 LIVE 脉冲 | 同上【参考提炼·需重新验证】 |
| 颜色配文字/形状 | 状态不只靠颜色，配文字/图标/填充/形状，无色也可懂 | 同上 + fork-clone/reports/status-20261116/design-review.md【参考提炼·需重新验证】 |
| 琥珀文字 vs 填充分离 | 琥珀作文字色时用更暗变体保对比（亮色环境），作底/描边仍用亮琥珀；分离「作文字」与「作填充」两种角色 | fork-clone/36-Jimmy设计语.md（WCAG 演进注）【参考提炼·需重新验证】 |
| 仪表轨道专用色 | 分段仪表空格用专用轨道色（对底 ≥3:1），否则读不出分母；不用面板色充当轨道 | 同上【参考提炼·需重新验证】 |
| 文字对比 ≥4.5:1 | 次级/三级文字对背景 ≥4.5:1；代价是第三级灰层次变弱（需权衡） | 同上【参考提炼·需重新验证】 |
| 告警侧线表严重性 | 收件箱行左侧色条（琥珀警告/红严重）表达严重性，行内动作右置 | 同上【参考提炼·需重新验证】 |
