# 03 订阅 token 生命周期

> 分类：【待验证】。**尚未实现**，见 roadmap/01。本流程是设计契约。

## 签发

1. 生成 ≥128bit 随机 token（`secrets.token_urlsafe`）。
2. **只存 hash + 元数据**（scope、线路 id 白名单、创建时间、有效期、配额、备注）。
3. 明文**只在签发响应里返回一次**；此后任何接口/日志/页面都不再回显完整 token。
4. 存储 0600；不入浏览器 localStorage。
5. 审计记录签发事件（记内部 id，不记明文）。

## 使用

- 端点 `GET/HEAD /sub/<token>`；token 走**路径段**，不走 query。
- 管理端点（列表/撤销/改配额）仍限内网（`X-FixCloud-Request: 1`）。
- 渲染按 scope 输出：自用版全量、朋友版只含白名单线路 id。
- 每次渲染后跑**泄露断言**：不得含回家节点凭据、external-controller/secret、上游 provider token、其他用户线路。

## 轮换

1. 签发新 token（旧 token 进入宽限期）。
2. 通知使用者更新（**通过既有可信通道，不在公开渠道发**）。
3. 宽限期结束后撤销旧 token。
4. 记录轮换事件。

## 撤销

1. 标记 revoked（保留元数据用于审计，**删除凭据材料**）。
2. 端点返回 404/410。
3. 使渲染缓存失效。
4. 审计记录。

## 有效期与配额

- `expire=0` 表示长期；否则 unix 秒。
- 超配额返回 403，并在 `subscription-userinfo` 反映用量。
- 无统计时给全 0，**不省略该头**。

## 禁止

- 不在错误响应里回显 token 或节点凭据。
- 不在访问日志记 token 明文（只记 hash 前缀或内部 id）。
- 不做 base64 订阅（Verge 拒收）。
- 不把自建节点凭据写进会被公开访问的主 YAML。
