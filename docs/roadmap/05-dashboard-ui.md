# 05 · Dashboard 监控与 UI 交互升级（P2）

> 分类：【待验证】方案。视觉与交互规范的正本在 [`design/`](../design/README.md)，本文件只列**功能级**升级。

## 1. 信息架构

沿用现有 `overview → list → detail`：

| 层 | 内容 |
|---|---|
| Overview | 舰队概览：节点数/在线数、本月流量、最近告警、订阅状态 |
| List | 节点列表（按 VPS 分组）、订阅 token 列表、来源列表 |
| Detail | 单节点详情（协议/端口/状态/延迟/流量/配置历史）、单 token 详情（scope/有效期/用量/撤销） |

**详情页头部**：左返回 / 中标题 / 右保存；**dirty 才显示"有未保存修改"**；保存必须进 Diff 评审流；**列表页不放全局保存**。

## 2. 紧凑监控卡（参考项目 + 我方规范）

| 要素 | 规则 |
|---|---|
| 单一 hero 指标 | 一张卡只强调一个数（如"本月已用流量"） |
| 配额条 | 有配额才显示；无配额显示"不限"而不是空条 |
| 新鲜度 | 低位小字"更新于 x 分钟前"，不抢主指标 |
| 状态强调色 | **只有一个**；颜色必须配文字/图标（色盲可达） |
| 空/加载/失败态 | 三态都要设计，不能只有成功态 |

## 3. 异步动作交互

- 必须 **busy 态 + 防重复点击**。
- 成功绿色 / 失败红色，**显示耗时**。
- 错误信息转**中文**，不直接抛后端英文栈。
- 长任务（部署/测速/批量发布）用进度或阶段提示，不要只转圈。

## 4. 凭据相关 UI

- 凭据**只留后端**；前端掩码显示；**不入 localStorage**。
- 订阅链接只在签发那一刻完整显示一次，之后掩码 + "重新生成"。
- 节点密码/UUID/私钥默认掩码，显式点击才短暂显示，且不写日志。

## 5. 新增页面清单（建议）

| 页面 | 优先级 | 依赖 |
|---|---|---|
| 订阅发布（token 列表/详情/签发/撤销） | P0 | roadmap/01 |
| VPS 舰队（巡检结果/资源/端口/防火墙） | P1 | roadmap/02 P1-a |
| 节点管理（自建节点 CRUD + 发布 + 回滚） | P1 | roadmap/02 |
| 监控（延迟/流量曲线/告警） | P2 | roadmap/04 |

## 6. 视觉层约束

- **必须复用当前生效的视觉层**，不要新建一套 CSS。当前生效层由 `design/02-panel-ui-current.md` 核实后确定（`style.css` 在 2026-11-22 有改动，旧结论不可信）。
- 暗色模式必须覆盖卡片/弹窗/字段/代码区。
- Mac 左侧持久导航 + 有界居中工作列；iPhone 全屏详情页 + 底部 tab + 44px 触达 + safe-area。

## 7. 验收

- 新页面在 Mac Safari 与 iPhone 上目视通过（含暗色）。
- 加载/空/离线/失败/dirty 五态齐全。
- 控制台无错误。
- **构建通过 ≠ 交互验收；HTTP 200 ≠ 数据路径正确。**
